ORDER CHECK — COMPLETE HTML APPLICATION

1. Unzip the entire folder.
2. On Windows, double-click START_WINDOWS.bat.
   On macOS, double-click START_MAC.command.
   On Linux, run START_LINUX.sh.
3. The app opens in the browser automatically.

Python 3.10 or newer must already be installed.
The Excel reader and timezone libraries are bundled. No pip, API key,
mailbox connection or internet access is needed to run the core app.

Keep the terminal window open while using the app.
Stop the app with Ctrl+C or by closing that terminal.

The HTML interface can run examples, check synthetic instructions,
read an Excel test attachment, and examine local email files.
It uses the same corrected Python engine and its regression tests.

For a view-only preview, open START_HERE.html directly. The 18 examples,
filters and case details work without starting Python. Run the launcher
to enable checks on new instructions or files.

See README.md for details and INTEGRATION.md for adapting another HTML page.
